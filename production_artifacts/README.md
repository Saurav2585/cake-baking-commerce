# Production Artifacts

Numbered folders are the durable handoff chain:

| Folder | Owner | Intended outputs |
|---|---|---|
| `00_project` | PM | Charter, backlog, status, governance |
| `01_research` | UX Research | Research plan, evidence, findings, recommendations |
| `02_brand_strategy` | Brand Strategy | Positioning, voice, naming and brand principles |
| `03_ux` | UX/Product Design | IA, journeys, flows, wireframes, content requirements |
| `04_ui_design` | UI/Product Design | Visual system and responsive specifications |
| `05_catalog_commerce` | Catalog/Commerce | Taxonomy, schemas, catalog, rules and boundaries |
| `06_visual_assets` | Visual Assets | Briefs, outputs, provenance and Asset Manifest |
| `07_motion` | Motion/GSAP | Motion system, reduced-motion and performance specs |
| `08_engineering` | Frontend Engineering | Technical plan, implementation notes and test evidence |
| `09_qa` | QA | Test plans, defect log and verification reports |
| `10_release` | Release | Release notes, deployment evidence and rollback plan |

Each folder remains empty until its authorized phase, except for approved task packages or placeholders explicitly created by the PM.
