# Cake Baking Commerce

An artifact-driven portfolio/demo ecommerce project for India-focused cake-baking ingredients, tools, bakeware, decorating materials, and packaging.

Phase 0 establishes governance only. No branding, UI design, catalog production, or application implementation has started.

## Repository map

- `AGENTS.md` — operating contract for all agents.
- `production_artifacts/` — numbered, phase-owned deliverables and handoffs.
- `docs/` — cross-phase decisions, risks, and release controls.
- `src/`, `public/`, `tests/` — reserved implementation surfaces; intentionally empty in Phase 0.
